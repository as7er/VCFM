# VCFM v152 - 赛制合理化改进

## 📋 改进概述

本次更新系统性地解决了游戏与现实足球联赛之间的时间逻辑矛盾，将赛制从"压缩但不合理"调整为"紧凑且合理"。

---

## 🎯 核心问题

### 原有设计的矛盾

```
原赛季设计：
├─ 赛季总长：约 180 天
├─ 联赛轮次：38 轮（20队双循环）
├─ 比赛间隔：7 天/轮
└─ 理论需求：38 × 7 = 266 天 ❌ 超出 46%！

时间冲突：
├─ 国际比赛日：每30天 × 6次 = 6 次
├─ 青训招募：每30天 × 6次 = 6 次
├─ 转会窗：夏窗35天 + 冬窗26天
└─ 杯赛+欧战：未计算但需额外时间
```

**结果**：时间严重不足，赛程密集度远超现实。

---

## ✅ 解决方案

### 1. 联赛规模：20队 → 18队

**文件**：`js/clubs.js`

#### 变更详情

| 项目 | 变更前 | 变更后 | 现实参照 |
|------|--------|--------|----------|
| 每级球队数 | 20 支 | 18 支 | 德甲18队、法甲18队 |
| 赛季轮次 | 38 轮 | 34 轮 | 德甲34轮 |
| 英格兰 D1/D2/D3 | 各20队 | 各18队 | 删除实力最弱2队 |
| 其他四国顶级 | 16 队 | 18 队 | 扩展power/money数组 |

#### 具体操作

```javascript
// D1: 删除 "galaxy" (Galeway United) 和 "zenith" (Zenith Borough)
// D2: 删除 "bastion" (Bastion United) 和 "mirage" (Mirage Town)
// D3: 删除 "anchor" (Anchorage FC) 和 "hearth" (Hearthfield Town)

// TOP_REALITY_CURVES 扩展至18个值
ESP: { power: [82,81,...,62,61], money: [56M,...,13M,12M] }
GER: { power: [82,78,...,62,61], money: [52M,...,13M,12M] }
ITA: { power: [79,78,...,63,62], money: [45M,...,13M,12M] }
FRA: { power: [81,76,...,60,59], money: [50M,...,9M,8M] }
```

#### 品牌数组调整

每个品牌数组从16-20个条目调整为18个，确保与球队数量一致。

### 2. 赛程间隔：7天 → 6天

**文件**：`js/models.js` (generateFixtures)

```javascript
// 变更前
day += 7;

// 变更后
const DAYS_BETWEEN_ROUNDS = 6; // 改为6天间隔，更紧凑的赛程
day += DAYS_BETWEEN_ROUNDS;
```

**计算**：
- 34轮 × 6天 + 3天开赛 = **207天**
- 相比原38轮×7天=266天，节省**59天**
- 更接近现实的"周中+周末"节奏

---

### 3. 国际比赛日：30天 → 50天

**文件**：`js/engine.js` (advanceDay)

```javascript
// 变更前
if (world.day - world.lastIntlDay >= 30 && !world.seasonOver) {

// 变更后  
if (world.day - world.lastIntlDay >= 50 && !world.seasonOver) {
```

**影响**：
- 207天赛季 ÷ 50天 ≈ **4次国际比赛日**
- 约在 D50, D100, D150, D200 触发
- 符合FIFA国际比赛日窗口频率（年4-6次）

---

### 4. 青训招募：30天 → 60天

**文件**：`js/engine.js` (processYouthDay)

```javascript
// 变更前
if (ya.daysSinceIntake >= 30) {

// 变更后
if (ya.daysSinceIntake >= 60) {
```

**理由**：
- 赛季内招募 **3-4次**（而非6次）
- 现实青训招募通常年1-2次，集中在赛季初/中
- 降低青年球员涌入速度

---

### 5. 转会窗时间调整

**文件**：`js/transfers.js`, `js/i18n.js`

| 窗口 | 变更前 | 变更后 | 天数 | 理由 |
|------|--------|--------|------|------|
| 夏窗 | D1–D35 | **D1–D50** | 50天 | 更接近现实60-90天 |
| 冬窗 | D120–D145 | **D130–D160** | 30天 | 后移避开密集赛程 |

```javascript
const SUMMER_START = 1;
const SUMMER_END = 50;    // 35 → 50
const WINTER_START = 130; // 120 → 130
const WINTER_END = 160;   // 145 → 160
```

