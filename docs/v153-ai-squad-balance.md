# VCFM v153 - AI阵容平衡检查系统

## 概述

为AI转会系统添加智能阵容平衡检查，避免AI球队出现8后卫3前锋等不合理配置。

## 问题诊断

### 旧AI转会逻辑的问题

**卖人决策**：
- 优先卖最弱球员（按总评排序）
- 不考虑位置需求
- 可能卖掉唯一的前锋，保留8个后卫

**买人决策**：
- 仅检查最弱位置人数 < 5
- 不考虑阵容上限
- 可能让某位置堆积到10+人

**结果**：
- AI球队经常出现极端失衡阵容
- 降低游戏真实性和挑战性

---

## 解决方案

### 1. 新增阵容平衡检查模块

**文件**：`js/squad-balance.js`（新增）

**核心功能**：
- `analyzeSquadBalance(players)` - 分析阵容平衡状况
- `canSellPosition(players, pos)` - 判断是否可卖该位置
- `shouldBuyPosition(players, pos)` - 判断是否需买该位置
- `selectPlayerToSell(players, filterFn)` - 智能选择卖出球员
- `selectPositionToBuy(players, money)` - 智能选择买入位置

**阵容标准**（基于现实足球）：
```javascript
GK:  2-3人   (理想2人)
DEF: 5-9人   (理想7人)
MID: 5-9人   (理想7人)
ATT: 3-7人   (理想5人)
总数: 18-25人
```

### 2. 增强AI转会逻辑

**文件**：`js/engine.js`（修改）

**卖人改进**：
```javascript
// 旧逻辑：卖全队最弱
const victim = sellable.sort(byWeakest)[0];

// 新逻辑：卖过剩位置中的最弱
const victim = selectPlayerToSellSmart(club.players, filterFn);
```

**买人改进**：
```javascript
// 旧逻辑：简单检查 count < 5
if (counts.GK < 2) needPos = "GK";
else if (counts[order[0]] < 5) needPos = order[0];

// 新逻辑：基于阵容平衡系统
const needPos = selectPositionToBuy(club.players, club.money);
if (shouldBuyPosition(club.players, needPos)) { ... }
```

## 测试结果

### 场景1：极端失衡（8后卫3前锋）

**初始状态**：
- GK: 2人, DEF: 8人, MID: 4人, ATT: 3人
- 问题：DEF过剩，MID严重不足

**AI决策**：
- 卖出：def8 (DEF, OVR=7, 年龄=33) ← 过剩位置最弱
- 买入：MID ← 优先补强短缺位置

**最终状态**：
- GK: 2人, DEF: 7人, MID: 5人, ATT: 3人
- ✅ 1轮转会达到平衡

### 场景2：理想平衡阵容

**状态**：
- GK: 2人, DEF: 7人, MID: 7人, ATT: 5人
- ✅ 无严重问题，AI不会乱买乱卖

### 场景3：门将过多（4门将）

**AI决策**：
- 卖出：gk4 (GK, OVR=9) ← 过剩位置最弱
- 优先处理过剩问题

## 技术实现

### 优先级算法

**卖人优先级**：
```javascript
过剩程度 = 当前人数 - 理想人数
排序: 过剩程度从高到低
限制: 不能卖到低于最小值
```

**买人优先级**：
```javascript
短缺程度 = 理想人数 - 当前人数
排序: 短缺程度从高到低
限制: 不能买到超过最大值
```

### 兼容性保证

- 旧存档自动应用新逻辑
- 如果新系统返回null，回退到旧逻辑（极端情况）
- 不影响用户手动转会
- 不改变转会窗口规则
