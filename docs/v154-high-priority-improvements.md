# VCFM v154 - 高优先级改进实施文档

## 概述

基于 v153 的深度代码分析，v154 完成了剩余3个高优先级改进：
1. **比赛日收入动态化** - 基于表现、对手、赛事的收入加成
2. **推进日事件反馈** - 关键事件摘要而非静默推进
3. **训练短期加成** - 赛前准备影响下场比赛

## 改进1：比赛日收入动态化

### 问题
原系统已有基础动态收入，但缺少：
- 表现加成（最近战绩）
- 赛季阶段加成（赛季末冲刺期）
- 系统化的加成计算逻辑

### 实施方案

#### 新增模块：`js/matchday-income.js`
提供系统化的收入加成计算函数（备用，当前已集成到 facilities.js）

#### 修改：`js/facilities.js`
在 `matchdayIncome()` 函数中新增两个参数：
- `formBonus` - 表现加成（基于最近战绩）
- `seasonPhaseBonus` - 赛季阶段加成（赛季末+10%）

### 加成系统

| 因素 | 加成幅度 | 触发条件 |
|------|---------|---------|
| 表现优异 | +15% | 积分率 ≥2.5 |
| 表现良好 | +8% | 积分率 ≥2.0 |
| 表现糟糕 | -5% | 积分率 <1.0 |
| 豪门来访 | +20% | 对手前3名 |
| 强队来访 | +10% | 对手前6名 |
| 德比战 | +25% | 同城/同级别宿敌 |
| 争冠大战 | +30% | 双方前4名 |
| 保级大战 | +30% | 双方倒数5名 |
| 欧冠决赛 | +50% | 决赛 |
| 欧冠半决赛 | +35% | 半决赛 |
| 国内杯决赛 | +40% | 决赛 |
| 赛季末冲刺 | +10% | 赛季进度85%+ |
| 赛季末关键期 | +5% | 赛季进度70-85% |

**上限**：单场最高2.5倍（欧冠决赛级别）

### 示例场景

**场景1：普通主场比赛**
- 基础收入：150,000
- 上座率：80%
- 实际收入：120,000

**场景2：赛季末保级大战德比**
- 基础收入：150,000
- 上座率：98%（保级战+德比）
- 表现加成：-5%（战绩不佳）
- 保级大战：+30%
- 德比战：+25%
- 赛季末：+10%
- 实际收入：147,000 × 0.95 × 1.30 × 1.25 × 1.10 = **236,000**（+97%）

**场景3：欧冠决赛**
- 基础收入：600,000（5级球场顶级联赛）
- 上座率：100%
- 表现加成：+15%（连胜）
- 欧冠决赛：+50%
- 实际收入：600,000 × 1.15 × 1.50 = **1,035,000**（+73%）

## 改进2：推进日事件反馈

### 问题
原 `advanceDay()` 和 `advanceToNextMatchDay()` 静默推进，用户错过：
- 转会窗开/关通知
- 重要球员伤病
- 挖角报价
- 青训招募
- 设施建设完工
- 董事会警告
- 关键AI比赛结果

### 实施方案

#### 修改：`js/engine.js`

**1. `advanceDay()` 返回 `events` 数组**
```javascript
return {
  userMatches,
  sacked,
  sackedResult,
  events, // 新增：关键事件列表
};
```

**2. 事件类型定义**
```javascript
// 转会窗事件
{ type: "transfer_window", phase: "summer_open" | "winter_open" | "closed" }

// 球员不满事件
{ type: "player_unhappy", player: "球员名" }

// 设施完工事件
{ type: "facility_completed", facility: "stadium" | "training" }

// 青训招募事件
{ type: "youth_recruitment", count: 3 }

// 国际比赛日事件
{ type: "international_break", day: 50 }

// 租借归还事件
{ type: "loan_returned", count: 2 }

// 关键AI比赛事件
{ type: "key_matches", matches: [
  { home: "曼城", away: "利物浦", homeGoals: 2, awayGoals: 2, derby: true }
]}
```

**3. 新增辅助函数**
```javascript
function checkTransferWindowEvent(world)
function checkYouthRecruitmentEvent(world)
function isTopTableClash(world, fixture)
function isRelegationClash(world, fixture)
```

**4. `advanceToNextMatchDay()` 累积事件**
```javascript
const allEvents = [];
while (days < maxDays) {
  last = advanceDay(world);
  if (last.events && last.events.length > 0) {
    allEvents.push(...last.events);
  }
  // ...
}
return { ok: true, days, events: allEvents };
```

### 事件优先级

**高优先级**（必须通知）：
- 董事会警告/解雇
- 转会窗开/关
- 球员不满/约谈请求
- 设施建设完工

**中优先级**（建议通知）：
- 青训招募
- 租借归还
- 国际比赛日

**低优先级**（可折叠）：
- 关键AI比赛结果
- 挖角报价

## 改进3：训练短期加成

### 问题
原训练系统仅影响长期成长（每周属性增长），无战术深度：
- 无法针对下场比赛准备
- 无法在重要比赛前调整训练重心
- 无法模拟"赛前备战"的真实感

### 实施方案

#### 新增模块：`js/training-boost.js`

**1. 训练模式定义**

| 模式 | 效果 | 代价 | 适用场景 |
|------|------|------|---------|
| **均衡训练** | 无特殊加成 | 无 | 常规比赛 |
| **进攻演练** | 下场比赛进攻+5% | 体能-2、受伤+5% | 对弱队主场 |
| **防守演练** | 下场比赛防守+5% | 体能-2、受伤+5% | 对强队客场 |
| **体能储备** | 体能+3%、受伤-10% | 士气-1 | 密集赛程 |
| **士气激励** | 士气+5 | 体能+1（轻松训练） | 战绩不佳时 |
| **定位球演练** | 定位球效率+15% | 受伤+2% | 对高大球队 |

**2. 核心机制**

**冷却时间**：3天（避免频繁切换）

**一次性加成**：每场比赛仅应用一次，避免重复生效

**加成传递链**：
```
训练模式 → 球员属性临时修正 → 比赛引擎修正器
```

**3. 代码示例**

```javascript
// 设置训练模式
setTrainingMode(club, "attack", currentDay);

// 比赛前获取加成
const boost = getMatchTrainingBoost(club, matchId);
// { attacking: +5, defending: 0, fitness: -2, morale: +1, injury: +0.05 }

// 应用到球员
const modified = applyBoostToPlayer(player, boost);
// player.fitness 85 → 83
// player.morale 60 → 61

// 转换为比赛修正器
const mods = trainingBoostToMatchMods(boost);
// { attackMod: 1.05, defenseMod: 1.0, injuryMod: 1.05, setpieceMod: 1.0 }
```

### 关键设计约束（改动时勿踩）

**`applyMatchPrepBonus()` 必须幂等。** `recomputeSides()` 在单场比赛内有 16 处调用
（换人、战术调整、中场、红牌等）。若按"首次调用后清零"实现，加成会在第一次
换人后凭空消失。"每场只生效一次"由赛后的 `resetMatchPrepCounter()` 保证，
不是由调用计数保证。

**`matchday-income.js` 的 `calculateMatchdayBonus()` 不能与 `matchdayIncome()` 叠加。**
两者都计算德比、杯赛阶段、争冠/保级加成，叠加会重复计算。与 `matchdayIncome()`
配合时只使用正交的 `getFormBonus()` 和 `getSeasonPhaseBonus()`。
